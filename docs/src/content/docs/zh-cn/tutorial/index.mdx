# ESP-OpenClaw-Node

面向 M5Stack StickS3 / ESP32-S3 的 OpenClaw Native Node 固件。

Gateway 负责 Agent、LLM、Memory、权限和路由；设备通过 WebSocket 提供经过身份认证、参数校验和能力边界限制的硬件执行层。

## 当前状态

- Native Node WebSocket、`connect.challenge`、`hello-ok` 和 Ed25519 Device Auth：已在真实 M5Stack StickS3 验证
- NVS 身份、稳定 Node ID、Gateway 配对和命令面批准：已验证
- 设备信息、状态、网络、按键、背光、重启和音频命令：已验证
- 受限文件和 Lua 脚本命令：已验证
- LVGL + Tiny TTF + NotoSansSC 中文显示：已验证
- 中文自动换行和受限天气符号图形替换：已实现，视觉结果仍需实体照片确认
- 稳定竖屏显示：已验证
- 真正运行时横屏：未完成

## 重要说明

当前稳定显示方向是竖屏。`orientation: landscape` 被接受或返回结果，并不代表 LCD 已经旋转。真正横屏必须同步重建 ST7789 panel、LVGL adapter、frame buffer、flush 坐标和 UI 页面。

## 显示命令

```text
device.screen.text
device.screen.clear
device.screen.fullscreen.enter
device.screen.fullscreen.text
device.screen.fullscreen.clear
device.screen.fullscreen.exit
```

`accepted`、`shown` 和 `cleared` 只代表命令被固件接受。文字边界、字体、图形替换、退出全屏和花屏情况必须通过真实设备照片或视频验收。

## 构建

已验证 ESP-IDF 5.5.4 / Python 3.9.6：

```bash
export IDF_PATH="$HOME/esp/esp-idf"
export IDF_PYTHON_ENV_PATH="$HOME/.espressif/python_env/idf5.5_py3.9_env"
source "$IDF_PATH/export.sh"
cd application/edge_agent
idf.py set-target esp32s3
idf.py reconfigure
idf.py build
idf.py -p /dev/cu.usbmodem101 flash
```

烧录前核对 M5Stack StickS3、ESP32-S3-PICO-1、8 MB Flash、8 MB PSRAM 和目标串口。

## 安全

默认固件不包含 Gateway 凭据：

```c
#define OPENCLAW_NODE_GATEWAY_URL ""
#define OPENCLAW_NODE_GATEWAY_TOKEN ""
```

临时联调凭据只允许放在本机未提交覆盖配置中。Gateway Token、Wi-Fi 密码、API key、私钥和连接字符串不得进入 Git、日志或文档。联调结束后恢复空 URL/Token，并把 Gateway 恢复为 `bind=loopback`。
